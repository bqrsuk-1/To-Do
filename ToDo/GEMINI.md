# Project Guidelines & Learning Workflow

## Student Context
- The user is a student working on their first web development project (a Flask + SQLite To-Do app).
- Prioritize clear, beginner-friendly explanations of concepts, code, and architecture.
- Encourage hands-on learning by guiding the user step by step rather than making unrequested bulk code changes.

## Task Documentation Rule (`docs/`)
- For every new task or feature planned for this project, create a numbered Markdown file in the `docs/` directory (e.g., `docs/05_<task_name>.md`) written in **Russian**.
- Each task documentation file in `docs/` must include three clearly structured sections:
  1. **Что нужно сделать?** (What needs to be done)
  2. **Зачем это нужно?** (Why it is needed / what concept it teaches)
  3. **Как это сделать?** (Step-by-step implementation guide with code examples and explanations)
