# To-Do
To-Do Project Week Site

# Full instruction how to use it on your own computer: 

# First you need to download few things:
  Install ToDo folder in zip with all files from github;
  Unzip this folder into any path you want;
  Install python manager (latest version);
  flask framework and Flask-SQLAlchemy from python(to do this after you install python manager, you need to write in terminal: pip install Flask, pip install Flask-SQLAlchemy);

# How to use it: 
  When you install everything you need, you need to check out from github repo files in correct order.
  
  After you install everything correctly you can in terminal run thin app
In terminal: go into main folder ( cd ToDo) and type python app.py, in terminal you will see HTTP:// link, copy and paste it in browser, congratulations, now you can use this app.

# Few examples how you can use this: 
  1) You can use it on your computer's browser to write task you need to do
  2) If your phone and computer are connected to one WiFi connection you can use this web app on your phone(to do this you need to allow 5000/tcp)

# How does it work: 
  You run a local host server on your computer and in browser you add, change status, delete any task you want, by doing this things in browser you work with database file on your computer.
